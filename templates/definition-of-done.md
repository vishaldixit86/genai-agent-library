# AI Engineer Definition of Done
- [ ] Acceptance criteria met and linked to evidence
- [ ] Changes scoped and reviewed
- [ ] Impacted contracts and call paths assessed
- [ ] Unit/integration/regression tests run, or gaps declared
- [ ] Security/privacy/permissions implications reviewed
- [ ] Decisions and code-flow documentation updated if relevant
- [ ] Observability, rollout and rollback assessed
- [ ] Required human reviews and approvals completed

This is a checklist, not proof that any check happened. CI is the enforcement boundary.
